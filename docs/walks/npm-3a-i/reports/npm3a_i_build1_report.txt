ELIGIBILITY: THE QUERY AND THE MIRRORED RULE
======================================================================
Order: shape -> actor status (one read of users/{actor}, used for the name too) -> DM-only accepted connection -> recipient preference -> userPrivate token -> marker -> send.

Connection query (eligibility.js, hasAcceptedConnection):
  db.collection("connections").where("participants", "array-contains", senderId).get()
  then, in code: status === "accepted"; participants includes the recipient; and {requesterId, addresseeId} equals {sender, recipient} in either order.
  Why this query:
    - It is scoped to the SENDER, so it never reads the connections collection unscoped. A test pins that it is the only query run.
    - A single-field array-contains is covered by Firestore's automatic single-field index, so it needs no composite index.
    - It matches the shape the mobile app writes, where participants = [requesterId, addresseeId].
    - The result set is the sender's own connections, so it is bounded.
  No limit() is applied, because a limit could cut off the one matching document.

Mirrored rule, firestore.rules lines 46 to 57 at 7e8750b, quoted in the eligibility.js header. The `let userPath` line is wrapped there for the 80-column lint.
    function isActiveUser() {
      let userPath = /databases/$(database)/documents/users/$(request.auth.uid);
      return !exists(userPath)
        || !('moderationStatus' in get(userPath).data)
        || get(userPath).data.moderationStatus == null
        || get(userPath).data.moderationStatus == 'active'
        || (get(userPath).data.moderationStatus == 'suspended'
            && get(userPath).data.suspendedUntil != null
            && get(userPath).data.suspendedUntil < request.time);
    }
  Mirror details:
    - An absent document is active; the push then names the actor "Someone".
    - An expired suspension is active.
    - A suspension with no suspendedUntil, or a non-timestamp one, is inactive, because the comparison cannot succeed in the rules either.
    - banned, and any other status, is inactive.
